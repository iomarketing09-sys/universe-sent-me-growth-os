# Instructivo: Configurar WhatsApp Business en el Celular – Flexi Piedras Negras

> **Para:** Equipo Flexi (quien tenga el número de WhatsApp Business)
> **Tiempo estimado:** 30-45 minutos
> **Requisitos previos:** Número de teléfono dedicado (que reciba SMS/llamada), admin en Meta Business Suite

---

## 📋 PASO 1: Descargar e Instalar

### En Android:
1. Abre **Google Play Store**
2. Busca **"WhatsApp Business"** (icono verde con "B" blanca)
3. Toca **Instalar** → **Abrir**

### En iPhone:
1. Abre **App Store**
2. Busca **"WhatsApp Business"**
3. Toca **Obtener** → **Abrir**

---

## 📋 PASO 2: Verificar el Número

1. **Acepta términos y condiciones**
2. **Ingresa el número de teléfono** de Flexi (ej: `+52 878 138 5284`)
   - ⚠️ **Importante:** Debe ser un número que **sí reciba SMS o llamada** (no VoIP)
3. Toca **Siguiente** → **OK** para recibir código por SMS
4. **Ingresa el código de 6 dígitos** que llegue por SMS
   - Si no llega: toca "Llamarme" para recibir llamada automatizada

## 📋 PASO 5: Etiquetas para Organizar Chats

Ve a: **⋮ → Herramientas de negocio → Etiquetas** → **+ Nueva etiqueta**

Crea estas **8 etiquetas** (colores sugeridos):

| Etiqueta | Color | Cuándo Usar |
|----------|-------|-------------|
| `🔥 Lead Nuevo` | Rojo | Primer mensaje de cliente nuevo |
| `🛍️ Interesado en Comprar` | Verde | Pregunta precios, stock, quiere comprar |
| `📏 Consulta Tallas` | Azul | Pregunta solo por tallas/medidas |
| `💰 Cotización Enviada` | Naranja | Ya enviaste precio/link de pago |
| `✅ Pedido Confirmado` | Verde oscuro | Cliente pagó / confirmó compra |
| 📦 `Enviado/Entregado` | Morado | Pedido en camino o entregado |
| `🔄 Cambio/Devolución` | Amarillo | Solicita cambio, talla equivocada, garantía |
| `⏳ Seguimiento Pendiente` | Gris | Cliente no respondió en 24h (recordar) |

**Cómo usar:** En cualquier chat → ⋮ → **Etiquetar chat** → Elige la que corresponda

## 📋 PASO 6: Conectar a Meta Business Suite (Para Anuncios + API)

> **Esto lo hace el admin de Meta Business Suite (puede ser ustedes o nosotros)**

### En computadora (business.facebook.com):

1. Entra a **Meta Business Suite** → **Configuración** → **Cuentas** → **Cuentas de WhatsApp**
2. **Agregar** → **Conectar número de teléfono**
3. Ingresa el **mismo número** que verificaste en el celular
4. Recibirás **código por SMS** en el celular → ingrésalo en la web
5. **Asigna a:** "Zapateria Flexi Piedras Negras" (Page ID: `361528203707668`)
6. **Completa verificación de negocio** (Meta lo pide para API + plantillas)
   - Documentos: Acta constitutiva / RFC / Identificación del representante
   - Tarda 1-2 semanas aprobar

## 🚨 ERRORES COMUNES Y SOLUCIONES

| Error | Qué Pasa | Solución |
|-------|----------|----------|
| "Número no válido" | Número no recibe SMS/llamada | Usa número físico con chip, no VoIP |
| "Ya existe cuenta" | Número ya tiene WhatsApp personal | Desinstala WhatsApp personal primero, respalda chats si quieres |
| No llega código SMS | Operadora bloquea o número mal escrito | Toca "Llamarme" / verifica código de país (+52 México) |
| Mensajes automáticos no salen | No activaste interruptor | Revisa: ⋮ → Herramientas → Mensajes automáticos → **Interruptores EN VERDE** |
| Plantillas Meta "Rechazadas" | Texto no cumple políticas | Revisa: sin mayúsculas excesivas, sin "gratis" engañoso, variables {{1}} correctas |
| No veo etiquetas en WhatsApp Web | Versión antigua | Actualiza WhatsApp Web (F5) o vuelve a vincular dispositivo |
