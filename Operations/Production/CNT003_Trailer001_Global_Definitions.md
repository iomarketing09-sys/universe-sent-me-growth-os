# CNT-003 Phase 2: Global Definitions

## Visual Style Specification

| Dimension | Value |
| :--- | :--- |
| **Sub-genre** | Fantasy illustration / storybook comic |
| **Rendering + Line** | 2D digital painting with thick ink outlines, comic-book style linework, cel-shaded shading |
| **Color + Lighting** | Rich saturated palette — warm golden/amber for interiors and character moments, cool blue-green bioluminescence for night forest, lavender/purple for cosmic/cloud scenes, dramatic chiaroscuro for climax |
| **Detail density** | Highly detailed backgrounds (foliage, architecture, cloud textures), moderate-to-high character detail with clear silhouettes |
